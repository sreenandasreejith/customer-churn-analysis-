# customer-churn-analysis-
📊 Customer Churn Analysis Dashboard – Power BI
📌 Project Overview

This project focuses on analyzing customer churn and customer behavior using an interactive Power BI dashboard. The objective is to identify key factors contributing to customer churn and provide meaningful insights that can help businesses improve customer retention and reduce churn.

The dashboard analyzes customer demographics, tenure, monthly charges, contract types, internet services, payment methods, and churn status.

🎯 Objectives
Analyze overall customer churn and retention.
Identify customer segments with higher churn rates.
Understand the relationship between contract type and churn.
Analyze churn based on gender and senior citizen status.
Compare churn across different internet service and payment methods.
Analyze customer tenure and monthly charges.
Provide an interactive dashboard for business decision-making.
🛠️ Tools & Technologies
Power BI – Dashboard development and visualization
Power Query – Data cleaning and transformation
DAX – Calculations and KPIs
Excel / CSV – Data source and preparation

💡 Key Insights

The analysis helps identify patterns such as:

Customers on month-to-month contracts represent an important churn segment.
Customers with different internet service types show different churn behaviors.
Payment methods can be compared to identify segments with higher churn.
Customer tenure and monthly charges provide useful indicators for understanding churn behavior.
Comparing churn across demographic and service-related attributes can help businesses develop targeted retention strategies.
